# Lessons

| Date | Category | What went wrong | Rule derived |
|------|----------|-----------------|--------------|
| 2026-10-13 | Tooling | A scripted regex replace of the `clip-diagonal-*` block in `globals.css` also consumed the closing `}` of `@layer utilities`. | After any scripted multi-line CSS edit, re-read the surrounding lines and run the build before moving on. |
| 2026-10-13 | Verification | Headless Edge with a tall `--window-size` made the `min-h-dvh` hero fill the whole shot, and a 390px width is clamped, so below-the-fold sections and mobile layout looked wrong/clipped. | Verify layout in a real browser tab; for mobile widths use a same-origin iframe of the target width, not headless window size. |
| 2026-10-13 | Tooling | The Read tool returned only line 1 of several files (hook-limited). | If Read is truncated, use `Bash`/`PowerShell` to print the file, then edit with exact strings. |
| 2026-10-13 | Tooling | `netstat ... grep LISTENING` found nothing on this German Windows, so a stale test server kept serving the old build and made new routes look broken (404, "unchanged"). | Kill test servers with `Get-NetTCPConnection -State Listen` (locale-independent) and confirm the port is free before re-testing. |
| 2026-10-13 | Process | Nine pages each hand-copied the same hero block (watermark, 11px eyebrow, font-black title), so restyling meant nine edits. | Shared page chrome lives in one component (`PageHeroSlider` takes title/subtitle props). Add new page heroes through it, not by copying markup. |
| 2026-10-13 | Tooling | A blanket `transition-all` → property-list replace also hit the header's inner bar, which animates `height`; the shrink would have stopped animating. | When narrowing `transition-all`, check which property each element actually animates before choosing the list. |
| 2026-10-13 | Tooling | `:focus-visible { border-radius: 2px }` changed the shape of every focused pill button. | Never set border-radius in a global focus style; outlines already follow the element's radius. |
| 2026-10-16 | nuLiga live API | `/time/<unix>` on the nuScoreLive REST API only accepts multiples of 15 s; anything else answers 204 (`meeting`) or 500 (`meetings`). Responses are CDN-cached for an hour, so the value also *is* the cache key — a 10 s bucket would have broken the live badge silently during a real game, and a fixed value serves hour-old scores. | Probe an undocumented API with fresh, non-round parameters before building on it; bucket the time to 15 s. Test live features against a mock that enforces the real constraints (`NULIGA_LIVE_REST_BASE` / `NULIGA_CLUB_TEAMS_URL` point the code at one). |
2026-10-16 · UI polish · Live components had no press feedback and a looping pulse on new ticker entries · Give every tappable live element an instant `:active` scale (disabled under reduced motion) and use one-shot fading highlights instead of infinite animations.
